# Теории

Платформа для публикации, обсуждения и голосования за теории и для отметки, сбылись они или нет. Это SPA на React 18, TypeScript, Vite и Tailwind CSS. Тёмная тема включена по умолчанию.

Данные лежат в `localStorage`. При первом запуске подставляются 10 демо-теорий разных категорий и статусов. В шапке есть переключатель RU / EN: интерфейс и демо-тексты показываются на выбранном языке, выбор сохраняется в браузере. Слой хранения собран в `src/utils/storage.ts`: чтобы перейти на REST API, Supabase или Firebase, замените `repository`, не трогая страницы.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Разделы

- `/` — лента, поиск, фильтры и сортировка
- `/theory/:id` — текст, голоса, обсуждение и статус
- `/add` — форма с проверкой и предпросмотром
- `/stats` — счётчик сбытия, топы и график по месяцам

Голос «за / против» и голос «сбылась ли» хранятся отдельно и ограничены одним выбором на теорию в этом браузере. Официальную отметку «Сбылась» с датой ставят автор или локальный модератор из меню профиля.
